##🌤️ Weather App
A simple weather app that shows real-time weather data for any city in the world, built with vanilla HTML, CSS, and JavaScript.


##🚀 Features
Search weather by city name
Displays temperature, weather condition, humidity and wind speed
Shows weather icon based on current condition
Press Enter key or click Search button to search
Error handling — shows message if city is not found or input is empty

##🛠️ Built With

-HTML5
-CSS3
-Vanilla JavaScript
-OpenWeatherMap API
-Fetch API & Promises

Go to openweathermap.org and create a free account
